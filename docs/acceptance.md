# 验证与恢复

当前默认模式核验程序安装、配置还原与 G HUB 启动，不以系统驱动或重启作为完成门槛。

公开源码的完整自动化测试在 Windows PowerShell 5.1 x64 执行，发布基线为442项通过。测试使用隔离目录与临时注册表键，部分测试只读调用 Windows 文件、驱动或服务盘点接口；不安装或切换真实 G HUB 环境。

真实安装与配置往返另外在开发机器验证，不能推断所有设备、功能或电脑都兼容。个人诊断记录、账户标识、历史配置和备份不随仓库发布。

出现异常时先选择恢复新版，保留状态与事务日志。不要直接删除受管理的环境、清单或备份。要卸载工具，应先选择退出管理并确认新版已恢复正常启动，再删除工具安装数据。
