# 验证与恢复

当前默认模式核验程序安装、配置还原与 G HUB 启动，不以系统驱动或重启作为完成门槛。

便携版完整自动化测试在 Windows PowerShell 5.1 x64 执行，464 项通过、0 失败。测试使用隔离目录与临时注册表键，包含真实 C/D 卷的文件交换、配置往返保留、复制失败、内容损坏、空间不足、删源中断、首次旧版捕获及布局恢复中断、目录锁、实例互斥和目录联接拒绝。部分测试只读调用 Windows 文件、驱动或服务盘点接口；这些测试不安装或切换真实 G HUB 环境。

真实安装与配置往返另外在开发机器验证，不能推断所有设备、功能或电脑都兼容。个人诊断记录、账户标识、历史配置和备份不随仓库发布。

运行数据与备份全部位于解压目录的 `Data` 中；便携版不部署到 `%ProgramData%\GHUBSwitcher`。备份在 `Data\Backups`，诊断在 `Data\Status`。准备后的路径绑定本机用户，不支持直接换目录或换电脑继续使用。

便携版暂停官方登录启动入口，仅登记普通用户按需启动任务，不安装 SYSTEM 开机恢复或后台监控任务。登录后从启动器启动 G HUB；异常时先选择 3 恢复新版，保留状态与事务日志。不要直接删除受管理的环境、清单、备份或跨盘暂存目录。要卸载工具，应先选择 8 退出管理并确认新版已恢复正常启动，再删除整个解压目录。
