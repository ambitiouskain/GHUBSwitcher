# 安装器审计范围

2026-09-26 起，新快照使用 `ScopeVersion: 1` 和 `GHubDependenciesV1` 选择规则。审计只做安装前后对比，不是系统快照，也不证明能撤销安装器对系统的所有影响。

## 采集内容

- 机器和登记用户的 `SOFTWARE\Logitech\GHUB`、`SOFTWARE\Logitech\LGHUB`，包括对应 `WOW6432Node` 路径，递归读取产品范围内的键和值。
- `registration.json` 已记录的产品根及具体卸载键。拒绝把 `SOFTWARE`、`SYSTEM\CurrentControlSet` 或卸载父键作为递归扫描根。
- 机器和登记用户的 32/64 位卸载父键只枚举一层，只递归采集 `DisplayName` 为 `Logitech G HUB` 或 `Logicool G HUB` 的条目。这可以发现安装器创建的新卸载 GUID；GUID 变化不等于审计选择规则变化。
- 机器和登记用户的 32/64 位 `Run`、`RunOnce` 逐值记录。不会把整个启动键认作 G HUB 所有；新增、删除或替换的每一侧必须分别匹配目标或源环境清单中的路径、值名和完整命令。
- 全局用户态服务、内核服务配置摘要、计划任务和设备类过滤器。用户态服务摘要含映像路径、账户、启动方式及服务类型；服务新增、删除和替换的每一侧分别匹配目标或源清单的服务名称和完整映像命令。内核服务摘要仅含路径、启动方式及服务类型，不含运行状态；只有名称和文件路径精确匹配源/目标内核组件清单的变更才可归类。
- 计划任务新增、删除和替换的每一侧，分别匹配目标或源清单的任务路径、任务名称及完整导出 XML 的哈希。每个任务必须有动作，且所有动作都是 Exec；每个 Command 展开环境变量并规范化后，必须位于活动 `Program Files\LGHUB` 目录内。包含外部可执行文件、非 Exec 动作或 XML 不符的任务不会因其他动作含 `LGHUB` 而获准。
- 切换器禁用原计划任务后，`Get-InstallerAuditSource` 可以生成仅供审计的源清单副本：任务身份必须已在原清单内，当前与原任务都必须满足 Exec 路径约束，且规范化后的 XML 必须相同，或仅 `Settings/Enabled` 变为 false。其他命令、参数、触发器、设置等变化均阻断；不会导入新的任务身份，也不修改恢复清单或服务 `Native` 配置。
- 共享文件范围：`System32\drivers`、CommonProgramFiles 下的 `Logitech` 和 `Logishrd`，逐文件哈希。明确排除 `System32\drivers\DriverData\LogFiles` 整个运行日志子树，枚举时不会进入该目录；驱动二进制及其他范围内文件的读取失败仍记入 `Errors`。

注册表对象逐项处理后释放；快照和差异报告保留 `ScopeVersion`、`ScopeSelectors`、实际 `RegistryRoots` 及 `NotAudited`。安装前后范围版本、选择规则和未审计声明必须一致。旧格式快照仍可按旧规则相互比较，但不能与新有界快照混合比较。

## 未采集与阻断条件

未审计范围包括上述产品/卸载/启动选择规则以外的注册表、服务依赖/延迟自动启动/失败动作/服务触发器、`System32\drivers\DriverData\LogFiles` 子树中的全部运行日志、共享目录以外的任意文件写入、未管理设备的绑定及未捕获依赖的 Driver Store 内容。日志排除以目录边界为准，不会忽略其他目录的权限、枚举或哈希错误。快照也不能确定某项变化来自安装器还是同时运行的其他软件。

范围内任意读取失败、范围声明不一致或无法按清单归属的变更仍会阻止登记。前后相同的不可读错误也不会被自动忽略。共享类过滤器及未知服务、内核服务仍需人工处理。范围说明不能替代官方安装、新旧驱动切换及鼠标实际功能验收。

此修改不改变安装或恢复步骤，不禁用系统服务，不删除驱动，不改动 G HUB 配置。实机只读审计的耗时与错误应先核实，再进入正式安装。
