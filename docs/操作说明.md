# G HUB 双版本切换器

把整个 ZIP 文件发给对方。对方在自己的电脑上解压到任意本地文件夹，双击 **GHUBSwitcher.exe** 即可启动；也可双击“启动切换器.cmd”。不要只发送 EXE 或 CMD。

支持 Windows 10/11 64 位，无需安装 Python、PowerShell 7 或开发工具。电脑上应先安装官方新版 G HUB；包内已包含经 Logitech 签名验证的 2021.3 安装器。首次部署和切换需要 Windows 管理员授权。

## 首次使用

1. 启动工具后按 Windows 提示允许部署。工具自动识别当前 Windows 账户，将程序安装到 `%ProgramData%\GHUBSwitcher`。
2. 在当前新版 G HUB 设置中关闭自动更新，选择 **5. 准备新版备份**，按窗口提示确认。工具保存这台电脑上的新版程序和配置。
3. 选择 **6. 首次安装并捕获旧版（交互向导）**。按向导通过官方界面卸载新版、安装包内的 2021.3，并关闭旧版自动更新。捕获完成后工具恢复新版。
4. 以后选择 **1** 启动新版、**2** 启动 2021.3。每次切换前保存当前版本最新的配置，切回来使用上次离开该版本时的配置。

菜单关闭后 G HUB 继续运行。以后可继续从解压目录启动；请保留 `%ProgramData%\GHUBSwitcher`，里面保存程序、两套环境和本机备份。包内不包含制作者的个人配置、账户或环境存档。

## 更新与恢复

新版更新由你操作：先启动新版，选择 **7. 维护更新新版**，完成官方更新、关闭自动更新，再按提示让工具接纳更新后的程序和配置。旧版配置会保留。请通过该入口登记更新，直接绕过工具更新会使原文件清单失效。

出现恢复提示时选择 **3. 恢复新版 / 续接重启**。选择 **4** 打开诊断目录。选择 **8** 退出工具管理并保留新版，备份和环境存档会保留。

默认按程序安装、配置恢复和 G HUB 实际启动确认结果，不以系统驱动状态或重启作为切换门槛。首次准备仍需按官方安装界面操作；本工具不会自动替你点击卸载确认。两版配置分别保留，硬件固件与板载设置由设备共享。

分发包经过隔离测试和本机验证；另一台电脑的设备与系统环境仍需在首次准备后确认。软件包内的哈希清单用于检查文件完整性，启动 EXE 本身没有商业代码签名。
